The Oracle is a social forecasting platform where users predict real-world events using points rather than money.

## Vision

Build a competitive forecasting community where people develop and demonstrate their ability to predict uncertain events.

## Prediction Categories

- Weather
- Sports
- Elections and public events
- Economics
- Technology
- General events

## Core Features

- User accounts
- Predictions
- Points
- Leaderboards
- Forecasting ratings
- Prediction history
- Automatic outcome resolution
- Forecasting statistics
- User ranks and titles

## Technology

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL

### Frontend
- Next.js
- TypeScript
